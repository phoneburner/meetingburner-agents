# CLAUDE.md

Read [AGENTS.md](./AGENTS.md): it is the one set of instructions for every
coding agent in this folder, Claude Code included.

To use MeetingBurner from Claude Code itself (join a meeting, take notes),
install the MeetingBurner MCP server:

```bash
claude mcp add meetingburner -e MEETINGBURNER_API_KEY=mb_your_key_here -- npx -y meetingburner-mcp@0.1.0
```
