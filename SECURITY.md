# Security

Please do not open a public issue for a security problem. Report it privately
through [meetingburner.com](https://meetingburner.com/developers) and we will
answer there.

Never paste an API key (it starts with `mb_`) into an issue, a pull request or
a log. If a key has leaked, revoke it at meetingburner.com, **Settings**,
**Developer**, and create a new one.
